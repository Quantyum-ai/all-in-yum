aiy Desktop - UX Design Directions

6 design direction explorations for the Electron wrapper

Project: aiy Desktop | Platform: Electron (macOS, Windows, Linux) | Design System: shadcn/ui + Tailwind CSS

Instructions: Below are 6 different design direction mockups. Each demonstrates the same 5 core screens (Workflows, Agents, Credentials, Privacy Mode, Logs) with different visual and interaction approaches. Compare how each direction handles privacy indicators, workflow execution, and keyboard-first navigation. Scroll through all 6 to find which direction best aligns with our "Trust + Speed" UX goal.

Key Features

  • Privacy badge always visible in header with shield icon
  • Green color scheme reinforces "safe" feeling throughout
  • Large privacy verification banner at top of every screen
  • Status indicators use green (local) / amber (hybrid) consistently
  • Privacy Mode screen prominent in navigation

Strengths

  • Maximum trust signaling
  • Clear for security-conscious users (Alex persona)
  • Visual consistency around privacy

Trade-offs

  • Privacy messaging may feel redundant to power users
  • Green color scheme limits flexibility
  • Banner takes valuable screen space

  • Command palette as primary interaction method (Cmd+K everywhere)
  • All actions accessible via keyboard without mouse
  • Fuzzy search across workflows, agents, credentials, logs
  • Keyboard shortcuts prominently displayed on navigation and palette results
  • Palette shows context-aware results (execute, view, configure)

Key Features

  • Real-time streaming log output as primary UI during execution
  • Privacy verification events inline with execution ([PASS]/[FAIL] markers)
  • Structured log entries with timestamps, levels, and messages
  • Auto-scroll option to follow execution in real-time
  • Cancel button always visible during workflow runs

Strengths

  • Maximum transparency (trust through visibility)
  • Perfect for debugging and auditing
  • Matches CLI behavior (familiar to terminal users)
  • Privacy checks visible in timeline

Trade-offs

  • Can be overwhelming with verbose logs
  • Requires filtering for long executions
  • Less visual polish than other directions

Recommendation & Next Steps

Recommended Combined Approach:
Based on our "Trust + Speed" goal and the 3 personas (Alex, Jordan, Sam), I recommend combining elements from Direction B (Workflow-Centric) + Direction C (Command Palette Native) + Direction A (Privacy-First):
  • Direction B layout - workflow cards as heroes for fast scanning
  • Direction C keyboard-first - Cmd+K command palette for power users
  • Direction A privacy - persistent privacy badge + inline verification
  • Direction F transparency - real-time log view during execution
