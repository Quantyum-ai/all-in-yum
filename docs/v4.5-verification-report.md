### Enhancement Recommendations (v4.6)

1. **Add Generator Recovery Mechanism**
   ```rust
   pub struct GeneratorFailoverConfig {
       // ... existing fields ...
       pub cooldown_duration: Option<Duration>,  // Time before retrying failed generator
       pub recovery_attempts: u32,                // Max times to re-enable
   }
   ```
   **Rationale:** If a generator API has transient downtime, allow recovery instead of permanent failover.

2. **Add Explicit Cascade Priority**
   ```rust
   pub struct GeneratorFailoverConfig {
       // ... existing fields ...
       pub priority_order: Option<Vec<String>>,  // Explicit priority vs Vec order
   }
   ```
   **Rationale:** Makes cascade order more obvious (currently implicit in `generator_fallback` Vec order).

3. **Add Weight Normalization Validation**
   ```rust
   fn validate_weights(&self, reviews: &[ProcessedReview]) -> Result<(), ConsensusError> {
       let total_weight: f64 = reviews.iter().map(|r| r.effective_weight).sum();
       if total_weight < 0.1 {  // Effectively no voting power
           return Err(ConsensusError::InsufficientWeight);
       }
       Ok(())
   }
   ```
   **Rationale:** Catch edge case where rogue enforcement reduces all weights to near-zero.
